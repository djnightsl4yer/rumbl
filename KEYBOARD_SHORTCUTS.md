# RÜMBL Keyboard Navigation Quick Reference

## Global Shortcuts

| Shortcut | Action |
|----------|--------|
| `Tab` | Move to next interactive element |
| `Shift + Tab` | Move to previous interactive element |
| `Enter` | Activate focused button or link |
| `Space` | Activate focused button |
| `Escape` | Close open modal or menu |

## Page Navigation

### Skip Navigation
- Press `Tab` immediately after page load
- First focusable element is "Aller au contenu principal" (Skip to main content)
- Press `Enter` to jump directly to main content

### Mobile Menu
- Press `Tab` to reach menu button
- Press `Enter` or `Space` to open menu
- Use `Tab` to navigate menu items (focus is trapped in open menu)
- Press `Escape` to close menu
- Focus returns to menu button after closing

## Form Navigation

### Input Fields
- `Tab` - Move to next field
- `Shift + Tab` - Move to previous field
- `Enter` - Submit form (when on submit button)
- `Space` - Toggle checkboxes/select dropdowns

### Error Handling
- Errors are announced to screen readers automatically
- Invalid fields have red borders and error messages below
- Use `Tab` to navigate to error messages

## Card Navigation

### Artist Cards & Event Cards
- `Tab` - Focus on card
- `Tab` again - Focus first link inside card
- `Enter` - Activate focused link
- `Shift + Tab` - Navigate backwards

### Social Links
Each card has social media links (Instagram, Shotgun, etc.):
- `Tab` to reach each link
- `Enter` or `Space` to open link in new tab

## Homepage Navigation

### Quick Access Buttons
From homepage, press `Tab` to reach:
1. Skip link (hidden until focused)
2. ACCUEIL (Home)
3. ÉVÉNEMENTS (Events)
4. NOS ARTISTES (Artists)
5. BOOKING
6. Instagram link
7. Shotgun link

Press `Enter` or `Space` to activate any button.

## Accessibility Features

### Visual Focus Indicators
- All focused elements have a **red outline** with glow effect
- Focus indicators are high contrast for visibility
- Never hidden, even for mouse users

### Screen Reader Support
- All interactive elements have descriptive labels
- Form errors are announced automatically
- Page changes announce new page title
- Loading states are communicated

### Focus Management
- Focus moves logically through the page
- Focus is never lost or trapped unexpectedly
- Modal dialogs trap focus until closed
- Focus returns to trigger element after closing dialogs

## Browser Compatibility

These keyboard shortcuts work in:
- Chrome (Windows, Mac, Linux)
- Firefox (Windows, Mac, Linux)
- Safari (Mac)
- Edge (Windows)

## Tips for Keyboard Navigation

1. **Start with Tab** - Press Tab immediately after page load to see the skip link
2. **Use Escape** - Quickly close any open menu or modal
3. **Visual Focus** - Look for the red outline to see what's focused
4. **Logical Order** - Tab moves left-to-right, top-to-bottom
5. **Don't Give Up** - All features are accessible via keyboard
